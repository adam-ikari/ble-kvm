# BLE KVM 需求规格说明书 v1.1

## 1. 目标

一台 ESP32-S3 实现的 USB-HID + BLE 双模 KVM 切换器。最多三台 PC 连接到设备——两台通过 BLE HID、一台通过 USB HID。设备通过物理按键（或逻辑状态）切换键盘/鼠标的受控主机，同时具备基本的自动化能力。

硬件：ESP32-S3（双核 Xtensa LX7，内置 Wi-Fi/BT/BLE 5.0、USB-OTG、GPIO、SPI/I²C/UART 等）。

---

## 2. 术语定义

- **PC1**：与设备保持 **第 1 路 BLE HID** 连接的主机（设备在 BLE 侧表现为 BLE HID 键盘 + 鼠标，作为 BLE Peripheral 同时维护最多 2 个 BLE HID 连接）。
- **PC2**：与设备保持 **第 2 路 BLE HID** 连接的主机。
- **PC3**：与设备保持 **USB HID** 连接的主机（设备在 USB 侧表现为 USB HID 键盘 + 鼠标）。
- **控制权（Ownership）** `owner ∈ {1, 2, 3}`：当前键盘/鼠标的输入路由目标。**owner = 1 时，键盘/鼠标输入发给 PC1（BLE HID #1）；owner = 2 时，发给 PC2（BLE HID #2）；owner = 3 时，发给 PC3（USB HID）。切换 owner 不会断开任何一端的 HID 连接。**
- **物理链（Physical Chain）**：PC1 ←(BLE)→ 设备 ←(BLE)→ PC2，以及 PC3 ←(USB)→ 设备。**各 PC 之间不能通过设备直接通信，设备不是数据转发器，仅做输入路由。**
- **受控 PC**：指当前 `owner` 对应的 PC。
- **非受控 PC**：指另外两台 PC。
- **输入（Input）**：指物理键盘、鼠标连接到设备后产生的 HID 事件。输入源可以是通过 BLE Central 连接的蓝牙键鼠、通过 USB Host 连接的有线键鼠、或设备自身产生的模拟输入（如触摸屏）。

## 3. 功能需求

### 3.1 核心功能：键盘/鼠标路由（KVM 切换）

#### 3.1.1 切换方式

- **FR-001**：设备提供物理按键，用于切换 `owner` 状态。
- **FR-002**：设备也可以通过 Web 管理面板切换 `owner` 状态。
- **FR-003**：切换是原子操作——一次切换，同时改变键盘和鼠标的路由目标。不允许键盘路由到一台 PC 而鼠标路由到另一台 PC 的部分切换状态。切换方式为循环已连接的 PC（1 → 2 → 3 → 1，自动跳过断开连接的 PC）。
- **FR-004**：每次切换完成后，设备应通过当前输出通道（Web UI、LED 指示灯、TFT 屏幕）明确报告当前 `owner` 状态。

#### 3.1.2 连接保持

- **FR-005**：切换 `owner` **不得断开任何一端的 HID 连接**。所有 BLE HID 连接和 USB HID 连接始终维持。
- **FR-006**：当 BLE HID 连接意外断开时，设备应自动尝试重连（可配置重连间隔和最大重试次数，参见 3.2.1.2）。

#### 3.1.3 切换时机

- **FR-010**：切换不要求等待"安全时机"（如没有按键按下时）。切换是即时生效的——在下一次 HID 事件到达时，路由到新的 `owner` 目标。这意味着"正在被按下"的键可能会在切换后"卡键"在旧的 PC 上直到物理释放，这是已知且可接受的行为（参见 8.1 已知限制）。

#### 3.1.4 低功耗休眠（仅电池供电硬件）

电池供电硬件（如 M5StickS3，`HAS_BATTERY=1`）支持低功耗休眠以延长电池续航。非电池供电硬件（如 M5StampS3）不支持休眠。

休眠采用两阶段递进：先熄屏，后休眠。休眠触发条件因当前输入模式而异。

- **FR-007**：**阶段一——屏幕熄灭**。触发条件：无任何用户交互（按键、触摸屏、Web 操作）持续超过 T_off 秒后，关闭显示屏背光并停止 LCD 刷新。T_off 可配置（秒，默认 30，通过 Web 管理面板可配置）。屏幕熄灭期间 BLE、USB、Wi-Fi 等所有功能正常运行。任何用户交互（按键、触摸、BLE 连接事件、USB 事件）立即重新点亮屏幕、恢复 LCD 刷新并重置计时器。

- **FR-008**：**阶段二——休眠**。触发条件取决于当前输入模式：
  - **KVM 模式**：所有 BLE HID 连接均断开且 USB HID 连接断开，持续超过 T_sleep 秒后进入休眠。
  - **PPT 模式**：IMU（陀螺仪 + 加速度计）持续无变化（变化量低于阈值）超过 T_sleep 秒后进入休眠。
  - T_sleep 可配置（秒，默认 60，通过 Web 管理面板可配置）。
  - 无物理按键触发休眠。

  休眠状态下：
  - **保持 BLE 广播**（PC 或键鼠扫描后可发起连接，连接成功即唤醒）
  - **LED 呼吸闪烁**（缓慢明灭，指示设备处于休眠状态）
  - 关闭显示屏背光并停止 LCD 刷新（若尚未关闭）
  - 关闭 IMU
  - 关闭音频编解码器
  - 关闭 Wi-Fi
  - 释放 USB HID 接口（USB D+ 下拉，使 PC3 检测到设备断开）
  - 进入 light sleep 模式（保留 RTC GPIO 和 BLE 唤醒源）

- **FR-009**：**从休眠唤醒**：
  - BLE 连接唤醒：PC 或键鼠通过 BLE 连接设备时自动唤醒
  - 物理按键唤醒（RTC GPIO）
  - USB VBUS 检测唤醒（PC3 重新上电）

- **FR-009a**：唤醒后自动恢复：BLE 连接、USB HID 接口、显示屏背光、IMU、音频、Wi-Fi（STA 模式自动重连，AP 模式重新启动），以及上次的 `owner` 状态和输入模式。LED 恢复常亮（指示当前 owner）。

### 3.2 设备管理

#### 3.2.1 连接管理

##### 3.2.1.1 角色定位

设备作为一台 "HID 透传器"，不仅是切换器，还需要主动管理两侧的 HID 连接。

- **FR-011**：**BLE 侧（对 PC1 和 PC2）**：ESP32-S3 充当 **BLE Peripheral + HID Device**，同时维护最多 2 个 BLE HID 连接（每个连接对应一台 PC）。广播自身，等待 PC 连接。广播名称默认为 `KVM-<MAC后4位>`（如 `KVM-A3F2`），硬件出厂即唯一。设备名可通过 Web 管理面板自定义。
- **FR-012**：**BLE 侧（对蓝牙键鼠）**：ESP32-S3 充当 **BLE Central**，主动连接蓝牙键盘/鼠标作为输入源。键鼠配对通过 Web 管理面板触发（参见 3.2.1.4 配对管理）。
- **FR-012a**：**USB 侧（对 PC3）**：ESP32-S3 充当 **USB Device（HID 键盘 + 鼠标）**。通过 USB-OTG 端口连接到 PC3。
- **FR-012b**：**USB 侧（对有线键鼠）**：ESP32-S3 充当 **USB Host**，通过 USB-OTG 端口连接有线 USB 键盘/鼠标作为输入源。**注意**：USB Host 与 USB Device 共享唯一的 USB-OTG 端口，两者互斥。当前默认使用 USB Device 模式（连接 PC3）；若用户需要使用有线 USB 键鼠作为输入源，需切换至 USB Host 模式（此时 PC3 不可用）。
- **FR-012c**：**BLE 并发能力**：ESP32-S3 BLE 控制器支持最多 8-9 个同时连接，NimBLE 配置 `BLE_MAX_CONNECTIONS=4`。设备同时维持以下 BLE 连接（总计最多 4 个）：
  - **2 个 Peripheral 连接**：PC1 和 PC2 各一个（设备作为 HID Device 被 PC 连接）
  - **最多 2 个 Central 连接**：蓝牙键盘和蓝牙鼠标各一个（设备作为 Central 主动连接键鼠）
  - 同时支持 BLE 广播（Peripheral 角色）和 BLE 扫描（Central 角色），无需切换模式。广播和扫描可并发运行。

##### 3.2.1.2 用户侧 - 参数配置

- **FR-013**：所有参数均支持通过 Web 管理面板或 API 配置。Web 管理面板通过 Wi-Fi 提供（ESP32-S3 工作在 AP 模式或 STA 模式），不受当前 BLE/USB 连接状态或 `owner` 状态的影响。

- **FR-014**：可配置参数分为**常用**（Web UI 暴露）和**高级**（仅 API 可调）：

  **常用配置（Web UI 暴露）：**
  - 设备名称（默认：`"KVM-<MAC后4位>"`）
  - 防休眠开关（默认：开）
  - 防休眠间隔 T（秒，默认：30，最小 10，0 = 禁用）
  - 屏幕熄灭超时 T_off（秒，默认：30，0 = 从不熄屏，仅电池供电硬件显示）
  - 休眠超时 T_sleep（秒，默认：60，0 = 从不休眠，仅电池供电硬件显示）

  **高级配置（仅 API）：**
  - BLE 广播间隔（默认：20ms）
  - BLE 连接参数（最小/最大连接间隔、延迟、超时）
  - BLE 自动重连开关（默认：开）
  - BLE 自动重连间隔（默认：30 秒）
  - BLE 最大重连次数（默认：0 = 无限重试）
  - USB Vendor ID（默认：0x303A = Espressif）
  - USB Product ID（默认：0x4001）
  - USB Manufacturer String（默认：`"Espressif"`）
  - USB Product String（默认：`"KVM HID"`）
  - `owner` 初始值（上电默认控制权，默认：`1` = PC1）

##### 3.2.1.3 非易失存储

- **FR-015**：所有配置参数存储在 ESP32-S3 的 NVS（Non-Volatile Storage）中。固件升级不会丢失配置。恢复出厂设置会清除所有配置（恢复为编译时默认值）。

##### 3.2.1.4 配对管理

- **FR-015a**：BLE 设备广播名称默认为 `KVM-<MAC地址后4位>`（如 `KVM-A3F2`），确保出厂唯一标识。设备名可通过 Web 管理面板自定义，自定义后广播名称同步更新。
- **FR-015b**：**配对模式**——默认情况下设备不接受新的 BLE PC 连接。用户通过 Web 管理面板点击"进入配对模式"触发：设备进入配对状态（LED 快闪），60 秒超时，期间 PC 可搜索并连接。超时后自动退出配对模式。已配对过的 PC 可自动重连，无需再次进入配对模式。键鼠的 BLE 配对同样通过 Web 面板触发。
- **FR-015c**：配对绑定数据存储在 NVS 中，最多支持 5 个绑定。超出限制时最旧的绑定被丢弃（FIFO）。Web 管理面板支持查看已配对设备列表、清除单个绑定、清除所有绑定。

### 3.3 防休眠（Anti-Idle）——"主动保持"

为防止受控 PC 因无操作而进入屏保/锁屏/休眠，设备可以在所有已连接的 PC 上定期注入无害的 HID 事件。

- **FR-016**：防休眠功能**对所有已建立 HID 连接的 PC 同时生效**（不仅仅是当前 `owner`）。若 PC1 已连接，则向 PC1 发送防休眠事件；若 PC2 已连接，则向 PC2 发送；若 PC3 已连接，则向 PC3 发送。所有已连接 PC 各自独立维护防休眠定时器。
- **FR-017**：防休眠**不受 `owner` 切换影响**——`owner` 改变后，所有已连接 PC 的防休眠定时器继续独立运行，不停止、不重置。每台 PC 的防休眠状态仅取决于该 PC 的 HID 连接是否存在。
- **FR-018**：防休眠事件类型：鼠标微移（±1 像素 Y 轴移动，发送后还原），不影响光标实际位置。支持通过 API 配置为 Scroll Lock 键（USB HID Usage ID 0x47）。
- **FR-019**：防休眠触发间隔 T（秒，默认：30 秒，通过 Web 管理面板可配置）。**防休眠定时器在每次检测到键盘或鼠标 HID 事件后自动重置**——即只有在键盘和鼠标都没有产生任何事件后，经过 T 秒空闲，才触发一次防休眠动作。每次防休眠动作后定时器重新计时（下一次触发需要再经过 T 秒空闲）。
  - T 必须 ≥ 10 秒（硬件强制下限）。
  - T = 0 表示完全禁用防休眠。
- **FR-020**：防休眠仅在**存在有效的 HID 连接**时执行。若某 PC 的连接断开，则暂停该 PC 的防休眠定时器，等待连接恢复后继续。
- **FR-021**：防休眠机制**对每台已连接 PC 独立生效**。切换 `owner` 不影响任何 PC 上的防休眠定时器状态。PC 的 HID 连接断开时，该 PC 的防休眠定时器暂停；重新连接后恢复。

### 3.4 USB 模式详情

- **FR-024**：ESP32-S3 在 USB-OTG 端口上运行 USB Device 模式或 USB Host 模式（互斥）：
  - **USB Device 模式**（默认）：同时暴露 HID 键盘接口（Boot Protocol） + HID 鼠标接口（Boot Protocol）。用于连接 PC3。
  - **USB Host 模式**：接受外接 USB HID 键盘/鼠标作为输入源。此模式下 PC3 不可用。
- **FR-025**：USB 键盘报告格式：标准 USB HID Boot Protocol 键盘报告（8 字节），支持标准 104 键及多媒体键映射。
- **FR-026**：USB 鼠标报告格式：标准 USB HID Boot Protocol 鼠标报告（4 字节：buttons, X, Y, wheel）。

### 3.5 BLE 模式详情

- **FR-027**：ESP32-S3 充当 BLE Peripheral，广播 HID Service（UUID: 0x1812），包含以下 GATT 特征：
  - **HID Information**（0x2A4A）
  - **HID Report Map**（0x2A4B）——键盘 + 鼠标报告描述符
  - **HID Control Point**（0x2A4C）
  - **Protocol Mode**（0x2A4E）——Boot Protocol / Report Protocol 切换
  - **Report**（0x2A4D）——Input Report（键盘/鼠标数据从设备到 PC）和 Output Report（键盘 LED 状态从 PC 到设备）
  - **Battery Service**（0x180F）——电池电量（0x2A19）
- **FR-028**：BLE 支持最多 2 个同时 Peripheral 连接（PC1 和 PC2）+ 最多 2 个同时 Central 连接（蓝牙键盘和鼠标），总计最多 4 个活跃连接。不接受超过 2 个 PC 的 BLE Peripheral 连接请求。
- **FR-028a**：ESP32-S3 同时充当 **BLE Central** 和 **Peripheral**，两个角色并发运行。Central 连接（键鼠）与 Peripheral 连接（PC）互不影响——Peripheral 广播和 Central 扫描可同时进行，无需切换模式。
- **FR-029**：BLE 安全模式：LE Secure Connections（Just Works 模式，无需 PIN 码）。配对绑定数据存储在 NVS 中。配对模式受 Web 面板控制（参见 FR-015b）。

### 3.6 物理输入（电路/GPIO 需求）

#### 3.6.1 开关控制

- **FR-030**：ESP32-S3 连接物理按键，用于手动切换 `owner`。电气形式：通过 GPIO 读取按键状态，内部上拉，外部接地。
- **FR-031**：按键状态变化触发 CPU 中断（双边沿触发），经过防抖处理（防抖时间为固件编译时常量，默认 50ms）。
- **FR-032**：当 `owner` 通过物理按键改变时，Web 管理面板应实时更新显示（通过 WebSocket 推送），无需手动刷新。

#### 3.6.2 物理按键

设备根据硬件平台支持不同数量的物理按键。按键行为由编译时 `HAS_SECONDARY_BUTTON` 宏区分。

##### 单按键硬件（如 M5StampS3、Generic ESP32-S3）

仅 1 个物理按键，只保留核心 KVM 功能，无模式切换：

- **FR-033**：单按键硬件提供 1 个物理按键（连接到 ESP32-S3 GPIO），功能如下：
  - **短按（< 3 秒）**：循环切换 `owner`（1 → 2 → 3 → 1 …，跳过未连接的 PC）
  - **长按 5 秒**：触发恢复出厂设置警告（LED 快闪）。
  - **继续按住至 10 秒**：确认执行恢复出厂设置。
  - **5-10 秒之间松开**：取消恢复出厂设置。
  - **双击（两次短按间隔 < 500ms）**：授权 Web 管理面板访问。

##### 双按键硬件（如 M5StickS3）

2 个物理按键——主按键（正面）和侧边按键。主按键负责核心 KVM 操作，侧边按键负责模式切换：

- **FR-033b**：**主按键（正面）**功能：
  - **短按（< 3 秒）**：循环切换 `owner`（1 → 2 → 3 → 1 …，跳过未连接的 PC）
  - **长按（≥ 3 秒）**：**无操作**（休眠由超时自动触发，无按键触发休眠）
  - **双击（两次短按间隔 < 500ms）**：授权 Web 管理面板访问

- **FR-033c**：**侧边按键**功能（模式切换）：
  - **短按（< 1 秒）**：在 PPT 模式下无额外功能；在 KVM 模式下触发 TFT 页面切换
  - **长按 1-5 秒**：循环切换输入模式——KVM 模式 ↔ PPT 演示模式（空中鼠标）。当前模式通过 TFT 屏幕和 Web UI 显示。
  - **长按 5 秒**：触发恢复出厂设置警告（LED 快闪）。
  - **继续按住至 10 秒**：确认执行恢复出厂设置。
  - **5-10 秒之间松开**：取消恢复出厂设置。

- **FR-033d**：**PPT 模式按键行为**：
  - **主键短按**：发送下一页（Page Down）
  - **主键双击**：发送上一页（Page Up）
  - **晃动设备**：IMU 空中鼠标控制光标
  - **侧键**：切换回 KVM 模式

> **设计依据**：所有硬件平台统一恢复出厂设置为两步确认（5 秒警告 → 继续按至 10 秒执行），防止误触。PPT 模式下侧键始终负责模式切换，主键负责翻页和光标控制。

- **FR-033a**：Web 管理面板认证方式为双击物理按键授权。前端在需要认证的操作（如修改配置、切换 owner）时弹出提示"请双击设备物理按键以授权"，设备检测到双击事件后通过 WebSocket 向前端推送授权令牌。令牌持久化存储（NVS），直到浏览器清除缓存或 token 过期才失效。不设用户名/密码登录机制。

#### 3.6.3 LED 指示灯

- **FR-034**：提供至少 3 个 LED（连接到 ESP32-S3 GPIO），分别指示：
  - **LED_1（绿色）**：常亮 = 当前 owner 为 1（PC1 受控）
  - **LED_2（蓝色）**：常亮 = 当前 owner 为 2（PC2 受控）
  - **LED_3（黄色/白色）**：常亮 = 当前 owner 为 3（PC3 受控）
- **FR-035**：额外的 RGB LED（如 WS2812/SK6812 可寻址 LED）：可用于显示 BLE 连接状态（闪烁 = 等待连接、常亮 = 已连接、灭 = 未连接），以及配对模式状态（快闪 = 配对模式中）。

### 3.7 显示需求

- **FR-036**：设备通过 SPI 接口驱动一个 RGB565 TFT LCD 显示屏（仅 M5StickS3）。显示屏显示设备状态信息（当前 owner、连接状态、电池电量、输入模式等）。**屏幕不用于显示 KVM 视频信号——设备不捕获、不传输、不切换视频。** Web 管理面板通过 HTTP/WebSocket 在用户自己的手机/电脑上访问，不在设备屏幕上显示。

### 3.8 其他硬件集成

#### 3.8.1 IMU（惯性测量单元）

- **FR-037**：ESP32-S3 通过 I²C 连接一个 IMU 模块（加速度计 + 陀螺仪），用于 PPT 模式下的空中鼠标和姿态检测（仅 M5StickS3）。
- **FR-038**：IMU 数据通过 Web 管理面板实时展示。数据刷新率 ≥ 10Hz。
- **FR-039**：IMU 数据在 KVM 模式下仅用于显示/监控目的，不参与 KVM 切换逻辑。
- **FR-040**：IMU 异常（如 I²C 通信失败）不应影响核心 KVM 功能。IMU 错误仅通过 Web UI 中的警告消息报告。

#### 3.8.2 音频

- **FR-041**：ESP32-S3 通过 I²S 接口连接一个 ES8311 音频编解码器（仅 M5StickS3），支持音频播放和录音。
- **FR-042**：音频播放能力：支持 TTS（文本到语音）合成和回放。
- **FR-043**：音频录音能力：语音输入功能——录音并通过云端 ASR 识别为文本，作为 HID 键盘输入发送到受控 PC。
- **FR-044**：音频功能独立于 KVM 核心功能，音频错误不引起系统故障，不影响键盘/鼠标路由。

### 3.9 触摸屏支持（未来路线图）

- **FR-046**：触摸坐标通过 USB HID 绝对坐标模式发送到受控 PC，实现"触摸屏模拟"。
- **FR-047**：触摸屏模式的进入/退出由 Web 管理面板中的虚拟按钮控制。

## 4. 软件需求（Web 管理面板）

### 4.1 功能范围

Web 管理面板是用户配置和监控设备的主要界面。所有前端代码及资源嵌入在固件镜像中，在 ESP32-S3 本地提供 HTTP/WebSocket 服务。

### 4.2 前端功能

- **FR-048**：**仪表盘（Dashboard）**——显示固件版本、BLE MAC 地址、owner 状态、各 PC 连接状态、键鼠连接状态、输入模式、Wi-Fi 信息、uptime。
- **FR-049**：**设备面板（Devices）**——PC 配对/连接管理（进入配对模式、查看已配对设备）、键鼠配对管理。
- **FR-050**：**网络面板（Network）**——Wi-Fi 模式切换（AP ↔ STA）、Wi-Fi 配置（SSID、密码）、IP 地址显示、Wi-Fi 扫描。
- **FR-051**：**设置面板（Settings）**——仅暴露常用配置项：
  - 设备名称
  - 防休眠开关 + 间隔
  - 屏幕熄灭超时（仅电池硬件显示）
  - 休眠超时（仅电池硬件显示）
  - 固件版本、OTA 更新入口
  - 恢复出厂设置按钮（需二次确认）
  - 高级配置通过 API 访问，不在 Web UI 暴露。

## 5. API 规范

### 5.1 HTTP API（通过 Wi-Fi）

**基路径**：`http://<device-ip>`，端口 80。

Web 管理面板中所有 API 均需要授权令牌（通过双击物理按键获取，参见 FR-033a）。令牌持久化存储，通过 `Authorization: Bearer <token>` 请求头发送。失败返回 `401 Unauthorized`。

#### 5.1.1 系统

- `GET /api/status` — 查询系统状态
- `POST /api/restart` — 软件重启 ESP32（保留 NVS 配置）

#### 5.1.2 控制

- `POST /api/owner` — 切换 `owner`（body: `{"owner": 1|2|3}`）
- `POST /api/pairing/start` — 进入配对模式（type: `"pc"` 或 `"keyboard"`）
- `POST /api/pairing/stop` — 退出配对模式

#### 5.1.3 Wi-Fi

- `GET /api/wifi/scan` — 触发 Wi-Fi 扫描
- `POST /api/wifi/config` — 设置 Wi-Fi 模式和 STA 凭证
- `GET /api/wifi/status` — 查询当前 Wi-Fi 状态

#### 5.1.4 BLE

- `GET /api/ble/scan` — 触发 BLE 扫描（返回可见设备列表）
- `POST /api/ble/bond-delete` — 删除指定已配对设备
- `POST /api/ble/bond-clear-all` — 清除所有已配对设备
- `GET /api/ble/bonds` — 查看已配对设备列表

#### 5.1.5 配置

- `GET /api/config` — 获取所有当前配置
- `PATCH /api/config` — 更新配置键值对

### 5.2 WebSocket API（通过 Wi-Fi）

**连接**：`ws://<device-ip>/ws`

- 通信格式：JSON 文本帧
- 消息类型（设备 → 客户端）：
  - `{"type": "state", ...}` — 状态更新
  - `{"type": "ble_status", ...}` — BLE 连接状态变化
  - `{"type": "usb_status", ...}` — USB 连接状态变化
  - `{"type": "log", ...}` — 系统日志
  - `{"type": "config", ...}` — 配置变更推送
  - `{"type": "gpio_action", ...}` — 按键事件通知

### 5.3 BLE GATT 管理接口（v1.1+ 路线图）

ESP32-S3 在 BLE 侧额外暴露一个自定义 Device Management Service，用于通过 BLE 对设备进行管理。

### 5.4 USB 串口管理接口（v1.1+ 路线图）

PC3 可通过 USB 虚拟串口（USB CDC ACM）发送设备管理命令。

## 6. 非功能性需求

### 6.1 性能

- **NFR-001**：`owner` 切换延迟（从物理按键按下到 HID 路由切换完成）< 50ms（排除防抖时间）。
- **NFR-002**：防休眠定时器精度 ±1%。
- **NFR-003**：BLE 输入延迟 < 10ms。
- **NFR-004**：Web 管理面板首次加载时间 < 3 秒。
- **NFR-005**：设备开机到可操作 < 3 秒。

### 6.2 安全性

- **NFR-006**：Web 管理面板使用双击按键授权机制（Bearer Token），令牌持久化存储。
- **NFR-007**：Wi-Fi 配置由 ESP-IDF 底层管理，不暴露明文密码。
- **NFR-008**：BLE 配对使用 LE Secure Connections（LE SC）。
- **NFR-009**：恢复出厂设置两步确认（5 秒警告 + 10 秒执行）。

### 6.3 可靠性

- **NFR-010**：BLE 连接意外断开后自动尝试重连。重连期间其他连接不受影响。
- **NFR-011**：设备持续运行 30 天不需要重启（内存泄漏 < 1KB/天）。
- **NFR-012**：配置写入 NVS 应原子化，防止断电损坏。
- **NFR-013**：工作温度 -20°C 至 70°C。

### 6.4 可维护性

- **NFR-014**：固件支持 OTA 更新（通过 Web 管理面板上传）。
- **NFR-015**：系统日志通过 WebSocket 实时推送，可通过 USB 串口查看。
- **NFR-016**：软件模块低耦合——各模块通过事件总线或回调通信。
- **NFR-017**：构建系统使用 CMake + ESP-IDF v5.x。

## 8. 附录

### 8.1 已知限制

- **卡键问题**：FR-010 描述——切换时正在按下的键可能卡在旧 PC 上直到释放。这是 KVM 硬件普遍存在的已知限制。
- **双 BLE 连接**：设备最多接受 2 个 BLE 主机同时连接（PC1 和 PC2）。
- **无视频切换**：本设备不支持视频信号切换。每台 PC 需要有各自的显示器。
- **USB Host/Device 互斥**：USB-OTG 端口同一时间只能运行一种模式。USB Host 模式下 PC3 不可用。
- **防休眠对所有已连接 PC 生效**：定时器在每次 HID 事件后重置，有真实用户操作时不会触发防休眠。
- **NVS 写入耐久性**：典型耐久性 100,000 次擦写周期。固件对相同值的重复写入进行去重。
- **BLE 配对密钥数量**：最多 5 个绑定，超出时最旧的被丢弃（FIFO）。
- **单按键/非电池硬件功能受限**：单按键硬件不支持模式切换（KVM/PPT）和低功耗休眠。休眠功能仅电池供电硬件支持。

### 8.2 未来路线图（v1.2+）

- USB CDC ACM 串口命令行
- BLE GATT 管理接口
- 触摸屏手势支持
- 外部 SD 卡日志存储
- 手机 App 配对触发
